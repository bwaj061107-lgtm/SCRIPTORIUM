What is Scriptorium?

Scriptorium is a cinematic manuscript engine. It is not merely an editor. It is a controlled production environment where story architecture, character continuity, call sheets, and genre atmosphere are forced to obey the active Engine Protocol. Every project you open behaves like its own private production, with its own workspace, its own visual identity, and its own rules.

Scroll this panel for the full manual — clearance roles, Studio ID formatting, identity protection, and a breakdown of every Engine Protocol currently online.

What is an Engine?

An Engine is a genre reality, built specifically for Scriptorium rather than borrowed from any one franchise. It changes the interface, the typography, the watermark, the animation language, and the architecture templates available inside a project. Eight Engine Protocols are online:

  • NORMAL A clean, neutral studio interface for modern and cross-genre writing.
  • DRAMA Grounded underworld tension — ledgers, smoke, and quiet threats behind closed doors.
  • FANTASY Ancient realms, bloodline oaths, and magic bound in old law.
  • HORROR Paranormal instability. Flicker logic. Hostile silence.
  • SCI-FI Deep-space survival, cold physics, and systems that can fail.
  • SUPERHERO Multiverse-scale power and consequence — masks, oaths, and collateral damage.
  • ROMANCE Entangled hearts, slow-burn tension, and the architecture of intimacy.
  • MYSTERY Cold cases, hidden motives, and the discipline of the unanswered question.

Engine Locking

Choosing one engine for a project locks it into Auteur Mode — the Soundstage will not allow switching away from it. Choosing several engines allows switching between only those selected engines inside that project. This keeps every production tonally disciplined.

Clearance Roles

Scriptorium now separates studio access into three clearances. Only one is active in this release — the other two are visible so you know what's coming, but registration and login are locked for them until the studio activates those portals.

  • WRITER — ACTIVE Full Studio Lot and Soundstage access. Create, rename, and delete productions, and write inside the Soundstage. This is the only clearance you can register today.
  • DIRECTOR — RESERVED Planned for full production oversight across a studio's productions. Registration is locked until this portal activates.
  • ACTOR — RESERVED Planned for read-only access to character sheets, call sheets, and dialogue sides. Registration is locked until this portal activates.

Your Studio ID

Every Studio ID is role-specific, so a Studio ID's domain tells you exactly which clearance it belongs to:

  • WRITER name_secondname.initial@s.writer.com — active and registerable now.
  • DIRECTOR name_secondname.initial@s.director.com — reserved for future release.
  • ACTOR name_secondname.initial@s.actor.com — reserved for future release.

Identity Protection

Because Scriptorium is open source and runs entirely in your browser, an early launch risk is identity squatting — someone registering a real director's or writer's name before that person ever signs up. This build adds three frontend-level safeguards against that:

  • RESERVED NAMES A small, extendable list of protected name combinations is blocked at registration.
  • UNVERIFIED BY DEFAULT Every new Studio ID is marked UNVERIFIED until the studio reviews it, so nobody can quietly pass as confirmed.
  • SELF-CERTIFICATION Registration requires confirming you are not impersonating a real person.

Be honest about the limits here: this is a frontend prototype, so none of it is tamper-proof against someone editing local code directly. A durable fix — invite codes, a reserved director registry, admin verification, a security PIN — needs a real backend, and is planned for a later phase.

Where Your Data Lives

This build stores accounts, sessions, and productions in your browser's local storage. Nothing is transmitted to a server. That makes it fast and private for a prototype, but it also means clearing your browser data or switching devices will not carry your productions with you — plan your exports accordingly.
